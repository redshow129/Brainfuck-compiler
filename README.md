<h1 align="center">BrainFuck Компилятор</h1>

<h2>Начало</h2>
Это компилятор написанный на C++, он переводит синтаксис языка в C++ код, а потом с помощью g++ компилирует, создан под Linux.


<h2>Что за "BrainFuck"?</h2>
Это такой язык программирования, где есть всего 8 команд.

| BrainFuck     |    Что делает                     |
| :---:         |   :---:                           |
|    +          |   Увеличивает текущий байт на 1   |
|    -          |   Уменьшает текущий байт на 1     |
|    >          |   Переместиться на след. байт     |
|    <          |   Переместиться на пред. байт     |
|    .          |   Вывод текущего синвола, код которого это значение текущего байта по таблице ASCII  |
|    ,          |   Ввод синвола в текущую ячейку   |
|    [          |   Начало цикла while. Условие - пока байт в текущей ячейке != 0   |
|    ]          |   Конец цикла while.|

<h2>Компиляция</h2>
Создайте файл с расширением .bf, напишите туда свою программу. Список команд и их значения выше.<br>
Скомпилируйте компилятор или воспользуйтесь <code>compiler</code> и вызовите его с терминала командой<br>
<code>./compiler [имя файла]</code><br>
и оно скомпилирует [имя файла] в out.<br>
Если не будет передано никаких параметров, то компилятор возмет <code>main.bf</code>.<br>
Если вы хотите посмотреть C++ код, то я его не удаляю, но у компилятора закоменчены строки для его удаления.<br>

На программу выделяется 30.000 байт, этого вполне достаточно

<h2>Про ЯП с википедии</h2>
<b>Brainfuck</b> — один из эзотерических языков программирования, придуман Урбаном Мюллером (нем. Urban Müller) в 1993 году, известен своим минимализмом. Название языка можно перевести на русский как вынос мозга (англ. brainfuck). Язык имеет восемь команд, каждая из которых записывается одним символом. Исходный код программы на Brainfuck представляет собой последовательность этих символов без какого-либо дополнительного синтаксиса.
<p><p>
Одним из мотивов Урбана Мюллера было создание языка с как можно меньшим компилятором. Отчасти он был вдохновлён языком FALSE, для которого существовал компилятор размером 2044 байта. Существуют компиляторы языка Brainfuck размером меньше 200 байт.<p>

Программы на языке писать сложно, часто приводится как один из ярких примеров «тьюринговской трясины» — тьюринг-полного языка, непрактичного в связи с примитивностью. Но при этом является вполне естественным, полным и простым языком и может использоваться при определении понятия вычислимости. Почти не используется для практического программирования (за исключением работ отдельных энтузиастов), а используется преимущественно для головоломок и задач для соревнований. Существует ряд диалектов языка, среди них — Spoon, LOLCODE, Whitespace, Feckfeck.
